# 店主微信话术（试点）

发给店主时用下面模板。App 名必须是 **No Menu Tonight**（店主 POS），不是消费者端 Tap List。

## 开户消息（绑定店主后复制）

```
【No Menu】{店名}
手机号：{11位手机号}
临时密码：{临时密码}

请安装 TestFlight 里的「No Menu Tonight」，用手机号+临时密码登录，登录后立刻改密码。
先只维护「今晚酒单」（上酒、枪号、图片）。点单功能默认未开通。
```

临时密码为字母+数字（例如 `Nm95953742`），无特殊符号，方便微信复制。

## 店主上手（发完账号后可再发）

1. 打开 **No Menu Tonight**（不是 No Menu / Tap List 消费者 App）
2. 输入手机号（11 位，不要加 +86）和临时密码
3. 按提示修改密码
4. 进入 **酒单** → 从商品库把今晚在售酒款加入今晚 → 设枪号
5. 重要酒款补图片
6. 消费者 App 里看到的「今晚」以你在 POS 设的为准

## 你（平台）验收后再做

- 开/关消费者端公开展示
- 按店开通点单（默认关）

## 员工

店主入驻 **不用邀请码**。员工由店主在「门店」里邀请（手机号 + 邀请码 + 初始密码）。
