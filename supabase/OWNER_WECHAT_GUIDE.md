# 店主微信话术（试点）

发给店主时用下面模板。App 名必须是 **No Menu Tonight**（店主 POS），不是消费者端 Tap List。  
Doc index: [`docs/INDEX.md`](../docs/INDEX.md).  
完整上手说明：[`OWNER_USER_GUIDE.md`](./OWNER_USER_GUIDE.md).

**Tonight App Store 状态：已上架（1.0.0）。** 新店主一律用「已上架」模板；勿再发 TestFlight / 审核中话术。

## 开户消息 — 已上架（当前）

```
【No Menu】{店名}
手机号：{11位手机号}
临时密码：{临时密码}

请在 App Store 搜索安装「No Menu Tonight」，用手机号+临时密码登录，登录后立刻改密码。
先只维护「今晚酒单」（上酒、枪号、图片）。点单功能默认未开通。
详细用法可看我们发的《商家端使用介绍》。
```

## 开户消息 — 审核中（仅历史备份，勿再发）

```
【No Menu】{店名}
手机号：{11位手机号}
临时密码：{临时密码}

「No Menu Tonight」正在 App Store 审核。请先用我们发的 TestFlight / 安装链接打开 App，用手机号+临时密码登录，登录后立刻改密码。
先只维护「今晚酒单」（上酒、枪号、图片）。点单功能默认未开通。
```

临时密码为字母+数字（例如 `Nm95953742`），无特殊符号，方便微信复制。

## 店主上手（发完账号后可再发）

可直接转发 [`OWNER_USER_GUIDE.md`](./OWNER_USER_GUIDE.md) 全文，或只发下面短版：

1. App Store 搜 **No Menu Tonight**（不是 No Menu）
2. 手机号（11 位）+ 临时密码登录 → 立刻改密码
3. **商品库** 录酒 → **加入酒单** → 设枪号
4. 重要酒款补图片；卖完点 **售罄**
5. **门店** 里改成 **已公开**，再保存二维码 / 发链接
6. 顾客网页和 No Menu App 里看到的今晚酒单，以你在 Tonight 设的为准

## 你（平台）验收后再做

- 开/关消费者端公开展示（店主也可在「门店」自己切换已公开/未公开）
- 按店开通点单（默认关）

## 员工

店主入驻 **不用邀请码**。员工由店主在「门店」里邀请（手机号 + 邀请码 + 初始密码）。
