# No Menu Tonight — 商家端使用介绍

给酒吧老板 / 值班同事看的说明。尽量不讲术语。  
App 名：**No Menu Tonight**（手机桌面可能显示成 **NM Tonight**）。  
顾客用的是另一个 App：**No Menu**。两个不要搞混。

Doc index: [`docs/INDEX.md`](../docs/INDEX.md).  
开户微信短消息：[`OWNER_WECHAT_GUIDE.md`](./OWNER_WECHAT_GUIDE.md).

---

## 一句话：这 App 干什么？

你在店里改「今晚有什么酒」，顾客立刻能在：

- 公开网页酒单
- 门店二维码
- 顾客 App「No Menu」

里看到。**不用再手写板、不用再改朋友圈图。**

---

## 两个最重要的概念（先记住就够）

| 你看到的名字 | 可以理解成 | 干什么 |
|---|---|---|
| **商品库** | 酒库 / 库存清单 | 店里所有酒的资料本；不一定今晚都上 |
| **酒单** | 今晚墙上那一排 | 顾客现在能看到的今晚酒 |

日常口诀：

1. 新酒先放进 **商品库**
2. 要上墙再 **加入酒单**
3. 卖完点 **售罄**；换酒就 **移出**（资料还在商品库）

## 怎么装、怎么登

1. iPhone 打开 **App Store**
2. 搜索：**No Menu Tonight**
3. 安装打开
4. 用我们发你的 **手机号 + 临时密码** 登录  
   （手机号填 11 位就行，不用写 +86）
5. 第一次会让你 **改密码**（至少 6 位）→ 改完再用新密码进

没有账号？联系 No Menu，或打开：  
https://nomenuapp.com/support?topic=bar_onboarding

员工入职：打开登录页 → **我有邀请码**（见文末「请同事帮忙」）。

## 打开后几个主页（底部）

大多数店只有这三个：

1. **酒单** — 今晚在卖什么（**日常最常用**）
2. **商品库** — 录入 / 改酒款资料
3. **门店** — 店名地址、公开/不公开、二维码、员工、活动

> 有的店会多出 **开台** 和 **订单** 两个 Tab（需 No Menu 为你开通）。没开通就不用管，默认没有。详见下文「开台与订单」。

## 第一次开通：按这个顺序做完就能给客人看

大概 15–30 分钟（酒多就再久一点）。

### ① 把门店信息填好

进 **门店 → 基本信息**

建议至少填：

- 展示名（客人看到的店名）
- 城市、地址
- 简介（可短）
- 营业时间（不想展示就选不展示）

保存。

### ②（可选但省事）设常用杯型

**门店 → 常用杯型**

例如：品鉴 150ml、半品脱 300ml、品脱 500ml。  
以后录酒时可以一键填杯型，不用每次手打。最多 4 个；这里只记名字和毫升，**不记价格**。

### ③ 把酒录进商品库

进 **商品库 → 新增商品**

常见要填的：

- 分类（如精酿 / 果酒；没有就先新建分类）
- 酒名
- 图片（相册选；尽量清晰）
- 酒厂（合酿可再加，最多 3 个）
- 风格、酒精度、产地、简介（有就填）
- 规格和价格（几毫升、多少钱）

小提示：

- 输入酒名时，可能会自动匹配「本店已有」或公共酒款资料，对上了能少打很多字
- 保存后可能会问：**要现在加入酒单吗？** 今晚要上就选加入

### ④ 把今晚要卖的酒加入酒单

先在 **酒单 → 设置** 确认本店固定酒头数量（只有店主可以改）。

三种做法都行：

- 在酒单里点一个 **空酒头 → 上酒**，直接搜索本店商品库
- 保存商品后直接「加入酒单」
- 或在商品库某一行点 **加入酒单**

从空酒头进入时，系统会记住枪号，不需要再选一次。其他入口加入时要选：

- **枪号**（墙上第几号；没有枪号就按你习惯排 1、2、3…）
- **状态**（新上的一般选 **上新**）

### ⑤ 公开给顾客看

进 **门店**：

1. 确认 **多渠道发布** 是 **已公开**
2. 需要展示价格就开 **展示价格**；默认是隐藏价格（很多店先隐藏）

公开之后，网页、二维码、顾客 App 会一起更新。

### ⑥ 保存二维码 / 分享链接

**门店 → 二维码 & 酒单链接**

- **保存**二维码到相册 → 打印贴吧台 / 桌贴
- **分享 / 复制**网页链接 → 发微信群、朋友圈

顾客 **不用装 App**，扫码或点开链接就能看今晚酒单。

若提示「二维码尚未开通」，微信联系 No Menu 帮你开通。

## 每天营业：几乎只用「酒单」这一页

### 新酒上墙

1. 在 **酒单** 里找到要上的空酒头，点 **上酒**
2. 搜索本店商品库：
   - 找到了 → 选中并确认上枪
   - 找不到 → 点「新增商品」；保存后选择加入当前酒头
3. 状态选 **上新**（或在售）

### 卖完了

酒单里点 **售罄**。  
点错了：屏幕下方会出现「撤销」，几秒内可点回去。

### 又有货了 / 继续卖

点 **恢复在售** 或 **标为在售**。

### 今晚先不上、但资料要留着

点 **移出**。  
酒还在商品库，以后还能再加回来。  
**枪号不会自动重排**，原位置会显示为空酒头，可以直接在这里上下一支。

### 临时不想让客人看见某一支（但还在酒单里）

点 **⋯ → 酒单隐藏**。  
之后还能设回公开。

### 枪换了 / 号乱了

点酒单上的 **#枪号**，改成新号（也可以和别的酒对调）。

### 酒头数量变了

店主点酒单右上角 **设置** 修改固定酒头数量。  
员工可以看到总数和空位，但不能修改。减少数量前，要先处理超出新数量的已用枪号。

### 改酒名、图、价格、简介

去 **商品库 → 编辑** 那支酒。  
改完后，已在酒单上的会跟着更新。

### 这酒彻底不卖了

商品库里 **下架**。  
（下架后一般不会再出现在今晚酒单。）

### 怕搞错客人看到的样子

酒单页点 **预览**，大致就是客人视角。

## 「门店」页还常会用到什么

| 入口 | 什么时候用 |
|---|---|
| **多渠道发布** | 营业就「已公开」；装修/暂停可改「未公开」 |
| **价格展示** | 想让客人看见杯型和价格再开 |
| **基本信息** | 改地址、简介、营业时间 |
| **常用杯型** | 录酒更省事 |
| **二维码 & 酒单链接** | 打印码、发链接 |
| **活动** | 有派对 / Guest Shift / 品鉴时做一张活动（要公开需先有海报） |
| **员工** | 只店主能进；请同事一起改酒单 |
| **经营数据** | 大概看商品数、上新、售罄情况（粗览即可） |
| **账户** | 改密码、退出登录 |

## 开台与订单（已开通门店）

若底部多了 **开台** 和 **订单**，说明你的店已开通轻量记账功能。  
**不处理收款**——App 只帮你记「谁喝了什么、多少钱」；客人实际付款仍在吧台另收。

### 两个 Tab 各干什么？

| Tab | 什么时候用 |
|---|---|
| **开台** | 营业中：开新桌、加点、快速结账 |
| **订单** | 查历史、搜客人、分享账单、结束营业日 |

口诀：**忙的时候用开台，收工对账用订单。**

### 开台（营业中）

1. 点右下角 **开台** → 填客人姓名 → 选酒、选规格 → 创建
2. 进行中的台会列在开台页；点进去可以继续加点
3. 客人要走时，点 **结账**（或进订单详情里标记已结账）
4. 顶部显示 **进行中台数** 和 **今日营业额**
5. 台多了可以用 **搜索客户姓名** 快速找到

小提示：

- 若今日营业日已结束，需要先点 **重新开始营业日** 才能开新台
- 已结账的单会从开台列表消失，可在 **订单** Tab 里查到

### 订单（查账 / 收工）

1. 按 **营业日** 分组显示所有订单
2. 可以按 **全部 / 进行中 / 已结账** 筛选，或 **搜索客户姓名**
3. 点某单可看明细，**分享账单** 发给客人或自己留档
4. 进行中的单可以 **继续加点**（跳到编辑页）
5. 误结账了、且营业日还没结束 → **恢复订单**
6. 当天所有台都结清后 → 在对应营业日点 **结束营业日**

**结束营业日后**，该日订单不能再改、也不能恢复。第二天会自动开新的营业日。

### 和酒单的关系

开台用的酒和规格，来自 **商品库** 里已上架、且设置了有效价格的酒。  
改商品库的价格或规格，**不会** 改已经开好的旧单（旧单会保留下单时的价格快照）。

## 请同事帮忙改酒单

店主账号 **不需要邀请码**（我们直接给你手机号+密码）。

请员工：

1. 店主进 **门店 → 员工**
2. 输入员工手机号 → **生成邀请码**
3. 把下面三项发给对方（微信复制即可）：

```
【No Menu 门店邀请】
手机号：……
初始密码：……
邀请码：……
请打开 No Menu Tonight →「我有邀请码」，填写以上三项加入门店。
```

4. 员工登录后通常要先改密码，然后就能进 **酒单** 一起维护

员工一般可以改酒单、商品库；**公开/不公开门店、邀请员工** 这类事给店主做更稳妥。

## 常见问题（老板最爱问的）

**Q：和顾客 App「No Menu」有什么区别？**  
A：Tonight 是给你改酒单的；No Menu 是给客人逛店看酒的。你改完，客人那边会更新。

**Q：必须先有商品库吗？**  
A：是。酒单是从商品库里「拎出来上墙」的，不是两套各录一遍。

**Q：移出和售罄有啥区别？**  
A：售罄 = 今晚还在单子上，但写着没了。移出 = 今晚单子上拿掉，资料还在库里。

**Q：为什么公开不了？**  
A：常见原因：店名/城市没填全；酒单里还没有可公开的酒；你开了「展示价格」但有的酒没填好价格。按提示补完再公开。

**Q：顾客必须下载 App 吗？**  
A：不用。网页和二维码就能看。有 App 的客人也可以在 No Menu 里看到你店。

**Q：开台、收款呢？**  
A：默认没有。若底部出现 **开台 / 订单**，说明已开通轻量记账（见上文「开台与订单」）。App **不处理支付**，只记消费明细；收款仍在吧台另收。

**Q：新建的酒资料会被改吗？**  
A：有时后台会帮忙校对公共酒款信息（名字、风格等），属正常；你店里的枪号、今晚状态、本店价格仍以你为准。

**Q：忘记密码 / 登不进去？**  
A：微信找 No Menu 支持重置。账号是门店开通的，不能自己在商店里注册。

**Q：一家店多个手机一起改？**  
A：可以。给员工发邀请，或店主账号登录多台设备（注意别互相覆盖同一操作）。
