## Typography Explorations

1. Helvetica Neue / Neue Haas direction: restrained Swiss grotesk, strong default recommendation.
2. Suisse Int'l / ABC Diatype direction: editorial, cultural, premium, less corporate.
3. Neue Montreal direction: contemporary independent magazine tone.
4. Univers / Akzidenz direction: colder, more brutalist, better for underground positioning.
5. Arial / system fallback direction: pragmatic implementation fallback for Expo and SVG rendering.

## Moodboard Keywords

- Editorial magazines: Monocle restraint, Kinfolk spacing, independent city guides.
- Music culture: Resident Advisor listings, Apple Music editorial, vinyl sleeve typography.
- Cinema and photography: A24 title-card confidence, film grain, late tungsten shadows.
- Tokyo nightlife: listening bars, narrow stairwell signage, black awnings, minimal door plaques.
- Luxury minimalism: black, off-white, bronze accent, no illustration, no explanation.

## Recommendation

Use the stacked `NO / MENU` mark as the primary brand logo and the minimal `NM` icon as the iOS app icon. Keep the bronze accent optional and sparse.
