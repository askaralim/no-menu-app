# No Menu Tonight brand

No Menu Tonight is the operator-side member of the No Menu product family. It
inherits the consumer Taplist v3 construction and adds `TONIGHT` as an
editorial sub-brand.

## Core lockups

- `no-menu-tonight-primary-stacked-dark`: default mark on the night surface.
- `no-menu-tonight-primary-stacked-light`: light-background alternative.
- `no-menu-tonight-primary-stacked-monochrome`: one-colour use on photography
  or constrained production.
- `no-menu-tonight-horizontal-dark`: wide-format application.
- `no-menu-tonight-icon`: square master artwork for app icons.

SVG files are the source of truth. PNG files are generated by
`tools/generate-brand-assets.mjs`.

| Role | Value |

| Dark-gold alternative | `#8A6A3A` |

## Usage

- Keep clear space around a lockup equal to at least half the height of `NO`.
- Use the full stacked lockup for splash screens, onboarding, and marketing.
- Use the square icon master only for app icons and favicons.
- Do not add a moon, star, drink, register, QR code, gradient, glow, or shadow.
- Do not recolour `TONIGHT` independently from its underline.
- Do not pre-round the iOS icon; the operating system applies its own mask.
- At very small sizes, use the generated icon export rather than the full
  horizontal lockup.
