# 酒单状态操作流程

适用端：POS App、小程序商户管理。

POS production 实现与发布记录：[`POS_RECOGNITION_OTA_2026-10-23.md`](./POS_RECOGNITION_OTA_2026-10-23.md)。

## 列表入口

- 点击酒款图片、名称或资料：直接进入编辑页面。
- 点击枪号：调整位置；目标位置已有酒款时执行交换。
- 点击状态标签或右侧更多按钮：打开酒款状态面板。
- 点击清空：将酒款移出当前酒单，但保留在本店商品库。
- 点击替换：为当前枪号选择另一款酒。

## 酒款状态面板

状态面板只处理以下内容：

- 供应状态：上新、在售、即将上新、售罄。
- 公开展示：酒单公开或酒单隐藏。
- POS App 保留状态记录入口；小程序暂未提供状态记录页面。

“编辑酒款”和“调整位置”不在状态面板重复出现，分别使用酒款资料和枪号入口。

## 状态规则

- 修改供应状态不会自动改变公开或隐藏设置。
- 隐藏只影响顾客端展示，不会将酒款移出酒单。
- 标记售罄后，POS App 保留原有的短时撤销能力。

## POS 代码位置

- `components/taplist/TaplistSlotRow.tsx`：枪号、编辑提示、状态入口和快捷操作。
- `components/taplist/DrinkStatusSheet.tsx`：供应状态、公开展示和状态记录入口。
- `app/(tabs)/taplist.tsx`：乐观更新、失败回滚、清空、换酒和枪号调整。
